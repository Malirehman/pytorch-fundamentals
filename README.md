# PyTorch Fundamentals

A beginner-friendly PyTorch notebook covering the fundamental concepts required to start learning deep learning.

## 📚 Topics Covered
- Installing and importing PyTorch
- Understanding tensors
- Scalars, vectors, matrices, and higher-dimensional tensors
- Tensor dimensions (`ndim`)
- Tensor shapes (`shape`)
- Random tensor creation with `torch.rand()`
- Tensor properties and inspection
- Basic tensor manipulation

## 🎯 Purpose
This repository documents my learning journey with PyTorch. The notebook focuses on understanding tensors—the core data structure in PyTorch—and provides hands-on examples for beginners.
